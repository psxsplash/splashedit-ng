One download per OS, with the editor, the example project, the psxsplash engine and pcsx-redux all included. Unpack it anywhere and run `splashedit`; nothing else needs installing.

- **Windows 10 or later:** `splashedit-windows.zip`. The executable is not signed, so SmartScreen may stop the first launch: More info, then Run anyway.
- **Linux x86-64, glibc 2.38 or newer** (Ubuntu 24.04, Debian 13, Fedora 39 and later): `splashedit-linux.tar.gz`.
- **macOS on Apple silicon:** `splashedit-macos.tar.gz`. The app is not notarized, so clear the download quarantine once before the first launch:
  `xattr -dr com.apple.quarantine splashedit`
